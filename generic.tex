\pnum
\X 中的实体可以带有编译器的类型或非类型参数进行泛化。

\pnum
紧随标识符且中间无空格的\tcode{<}视为泛型参数的开始。\tcode{<}与标识符之间有空白时视为小于运算符。\enterexample
\begin{codeblock}
a<b>   // 泛型参数，< 紧贴 a
a < b  // 比较，有空白
\end{codeblock}
\exitexample

\rSec1[kind]{高阶类型}
\indextext{高阶类型}

\rSec1[generic.impl]{\tcode{impl}泛型}
\indextext{泛型!\idxcode{impl}}

\pnum
如果\tcode{impl}被用于一个函数的参数类型中，则其相当于一个匿名的泛型参数。

\enterexample
\begin{codeblock}

func f(a: impl A) { }

// 等价于
func<T impl A> f(a: T) { }

\end{codeblock}
\exitexample
