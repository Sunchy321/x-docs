\pnum
\X 中的实体可以带有编译器的类型或非类型参数进行泛化。

\pnum
实体也可以带有生命期参数，用于引用类型中表达借用有效性约束（\ref{type.ref}）。生命期参数与类型参数并列于\tcode{<}、\tcode{>}之间，例如\tcode{func<'a, T> f(x: T '$a$ \&) -> T '$a$ \&}。

\pnum
实体也可以带有编译期值参数，形如\tcode{<const $S$: $T$>}，其中$S$是类型$T$的编译期值。符号字面量（\ref{literal.symbol}）可用于此类位置，例如\tcode{<const $S$: Symbol>}。

\pnum
泛型参数可以携带\tcode{if}约束，形如\tcode{<const $N$: int if $N$ > 0>}。\tcode{if}约束是编译期布尔门槛：在一次使用中泛型实参全部代入后，约束表达式作为编译期表达式求值；求值为\tcode{true}则约束满足，求值为\tcode{false}则该泛型声明不适用于此次使用——与特征约束不满足在相同的位置、以相同的方式构成编译错误。

\pnum
约束表达式中可以引用同一参数列表中先声明的\tcode{const}值参数，以及编译期可见的常量与编译期函数。类型参数与生命期参数不作为约束表达式的操作数；对类型参数的结构性约束应当使用类型约束或\tcode{impl}约束表达。\tcode{if}约束不参与类型推导，也不产生类型信息。若使用点的泛型实参在类型推导结束后仍未完全确定，则无法求值的约束视为不满足（保守拒绝）。

\pnum
紧随标识符且中间无空格的\tcode{<}视为泛型参数的开始。\tcode{<}与标识符之间有空白时视为小于运算符。\enterexample
\begin{codeblock}
a<b>   // 泛型参数，< 紧贴 a
a < b  // 比较，有空白
\end{codeblock}
\exitexample

\rSec1[generic.impl]{\tcode{impl}泛型}
\indextext{泛型!\idxcode{impl}}

\pnum
如果\tcode{impl}被用于一个函数的参数类型中，则其相当于一个匿名的泛型参数。

\enterexample
\begin{codeblock}

func f(a: impl A) { }

// 等价于
func<T impl A> f(a: T) { }

\end{codeblock}
\exitexample
