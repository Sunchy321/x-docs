\rSec0[deduct]{类型推导}
\indextext{类型推导}

\pnum
\X 可以在适当的地方不提供显式类型，而是让类型自动推导。

\rSec1[deduct.static]{自动推导的静态成员}

\pnum
使用类型的静态成员和枚举符时，可以省略类型名称。

\pnum
匿名静态成员表达式$e$按照如下方法匹配类型$T$：

\begin{itemize}
    \item 如果$T$是枚举类型，且具有枚举符$e$，且枚举符参数与$e$匹配，则匹配成功。
    \item 否则，如果$T$具有类型为$T$的静态成员$e$，且$e$不含有枚举符参数，则匹配成功。
    \item 否则，如果$e$是函数类型的表达式，且$T$具有名称为$e$、返回类型为$T$的静态方法，且\tcode{$T$.$e$}的参数类型与$e$的兼容，则匹配成功。
    \item 其他情况匹配失败。
\end{itemize}

\enterexample
\begin{codeblock}
enum E { A, B(int), C };

class X {
    static let x = X();
    static func v(i: int) => X();
    init() { }
}

func f(e: E) { }
func g(x: X) { }

f(.A); // 可以
f(.B); // 错误，枚举符参数不一致
f(.B(0)); // 可以
g(.x); // 可以，等价于\tcode{g(X::x)}
g(.v(0)); // 可以，等价于\tcode{g(X::v(0))}

\end{codeblock}
\exitexample

\pnum
匿名静态成员表达式匹配可以跨越方法调用。对方法调用\tcode{$o$.$f$}而言，如果$T$有方法$f$其类型与\tcode{$o$.$f$}兼容，且返回类型为$T$，则\tcode{$o$.$f$}匹配$T$当且仅当$o$匹配$T$。

\enterexample
\begin{codeblock}
enum E { A, B(int), C };
enum F { X, Y, Z };

impl E {
    func f() => self::C;
    func g() => F::X;
}

impl F {
    func f() => E::A;
    func g() => E::C;
}

func f(e: E) { }

f(.C.f()); // 可以，推导可以穿过方法调用，且只会检查\tcode{E.f}
f(.Y.g()); // 错误，\tcode{E}上的方法\tcode{g}不返回\tcode{E}

\end{codeblock}
\exitexample

\rSec1[deduct.basic]{基本推导与双向推导}

\pnum
类型推导本质上是以类型变量求解约束方程组的过程。在需要类型但未显式指定的位置，编译器引入一个类型变量$\mathcal{?T}$，收集该变量参与的所有约束，然后通过合一（unification）求解。

\pnum
\term{基本推导}指从表达式向上推导类型的过程。\enterexample
\begin{codeblock}
let x = 42;         // 42 的类型为 int，因此 x 的类型为 int
let y = x + 1;      // 1 的类型为 int，+ 要求两个操作数类型相同，因此 y 的类型为 int
let z = true;       // true 的类型为 bool，因此 z 的类型为 bool
\end{codeblock}
\exitexample

\pnum
\term{双向推导}指类型信息同时沿两个方向流动：表达式向上提供类型，上下文标注向下提供预期类型。当同时存在时，预期类型被用于约束表达式内的类型变量推导。\enterexample
\begin{codeblock}
let a: int? = nil;           // nil 的类型为 ?T?，上下文要求 ?T? = int?，解出 ?T = int
let b: string? = nil;        // 同上，解出 ?T = string
let c = nil;                 // 编译错误：未能在函数体内确定 ?T
\end{codeblock}
\exitexample

\pnum
函数调用时，实参类型用于推导函数的泛型参数类型。\enterexample
\begin{codeblock}
func identity<T>(x: T) -> T { x }
let v = identity(42);        // 实参 42 的类型为 int，推导 T = int，v 的类型为 int
\end{codeblock}
\exitexample

\pnum
如果泛型函数带有 trait 约束，则推导过程中同时求解约束。若约束无法满足，报编译错误。\enterexample
\begin{codeblock}
func add<T : Add<int>>(a: T, b: int) -> T { a + b }
let v = add(3.0, 1);         // 实参 3.0 的类型为 float，推导 T = float，检查 float : Add<int>
\end{codeblock}
\exitexample

\pnum
类型推导的作用范围是当前函数体。函数体内的未解变量在函数体结束时必须全部确定。返回类型的推导跨越整个函数体——所有 \tcode{return} 表达式的公共类型为函数的返回类型。

\pnum
泛型声明的适用性条件由特征约束（\tcode{:}、\tcode{impl}形式）与\tcode{if}约束共同构成，按逻辑与求解。求解顺序如下：由实参推导解出泛型参数；代入并求值\tcode{if}条件，不成立则声明不适用；求解特征约束，选择唯一适用实现（重叠判定见\ref{impl}）；求解过程中归一化类型中的投影——例如\tcode{$I$::Item}在\tcode{$I$}具体化时约简为其关联类型（\ref{name.lookup}）。不可判定的条件保守视为不满足（\ref{generic}）。
