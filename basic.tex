\rSec0[basic]{基本概念}

\pnum
\term{实体}包括对象、函数、类型、模块、运算符、扩展。

\rSec1[value-model]{值模型}
\indextext{值模型}

\pnum
\X{}采用\term{默认移动语义}。赋值（\ref{expr.assign}）与按值传参（\ref{param.qual.mut}）转移值并使源位置失效；复制必须显式\tcode{clone()}。\tcode{return}同样以转移方式把结果移交给调用方（\ref{stmt.control}）。

\pnum
\term{可复制类型}的值不受移动语义约束：整数类型、浮点类型、\tcode{bool}、\tcode{char}、\tcode{string}与\tcode{Symbol}的值在赋值、按值传参与\tcode{return}中被复制而非转移，源位置不失效，可继续使用。其中\tcode{string}的复制共享其字符内容（\ref{type.funda}）。

\pnum
处于失效状态的位置不能被读取、移出或取引用；对它的任何使用都是编译错误，直到它被重新赋值。指向它的引用按其生命期与借用检查规则处理（\ref{type.ref}）。

\pnum
\term{位置}是保存值的存储单元，可以被读取、赋值更新、取引用（\ref{type.ref}）与移出。位置不对应实际的内存地址，实现可以任意搬移它——引用指向位置本身，搬移后仍保持有效。变量绑定某个位置；整体值的字段与数组/映射元素是该位置的子位置。字面量与临时表达式取引用时物化为匿名的临时位置。引用类型（\ref{type.ref}）\tcode{$T$\&} / \tcode{$T$ mut\&}是位置的别名，可携带生命期表达借用有效性约束。活引用不得跨越其目标位置的消费点；生命期可显式标注，未标注处由编译器推断。

\pnum
GC 负责逃逸位置的内存存活。普通值没有确定性析构，资源责任由线性类型（\ref{core.linear}）承担。闭包捕获按最小捕获原则推断为引用捕获，闭包体移出变量时升格为移动捕获（\ref{expr.closure}）。

\rSec1[scope]{作用域}
\indextext{作用域}

\pnum
\term{作用域}是一段程序文本。特定的语言功能可能只能在特定的作用域中生效。不同的作用域具有不同的类型，分别被不同的语言功能所引用。作用域可以互相包含。

\pnum
\term{全局作用域}是整个程序文本代表的作用域，包含所有其他作用域。

\rSec2[scope.decl]{声明作用域}
\indextext{作用域!声明}

\pnum
声明作用域限制声明的范围。一个声明或绑定将会被插入到最近的声明作用域中，并且在该作用域内可以使用该名称引用被声明的实体。
在离开该作用域之后，被声明的实体将不能被使用该方式引用。

\pnum
所有的语句都具有声明作用域。全局作用域也是声明作用域。

\rSec2[scope.func]{函数作用域}
\indextext{作用域!函数}

\pnum
函数作用域限制\tcode{return}语句、\tcode{throw}语句的使用。参见~\ref{stmt.control}。

\pnum
函数作用域也限制\tcode{await}运算符的使用。参见~\ref{expr.await}。

\pnum
函数定义的块、闭包表达式的块或表达式、立即闭包表达式的块或表达式和函数调用表达式的闭包块具有函数作用域。

\rSec2[scope.closure]{闭包作用域}
\indextext{作用域!闭包}

\pnum
闭包作用域限制匿名闭包参数的使用。参见~\ref{lex.closure-args}。

\pnum
闭包表达式的块或表达式以及函数调用表达式的闭包块具有闭包作用域。

\pnum
属性的访问器也具有闭包作用域。参见\ref{impl.prop}。

\rSec2[scope.sequence]{序列作用域}
\indextext{作用域!序列}

\pnum
序列作用域限制\tcode{\textasciicircum}和\tcode{\$}的使用，参见~\ref{expr.bound}。序列作用域有一个关联的当前序列值，无论它是否实现\tcode{Sequence}。

\pnum
下标运算符\tcode{$s$[$\ldots$]}的两个方括号之间具有序列作用域。其当前序列为$s$。

\pnum
函数调用表达式\tcode{$s$($\ldots$)}的括号之间具有序列作用域。如果$s$形如\tcode{$o$.$f$}，且$f$是一个方法，则其当前序列为$o$，否则当前序列为$s$。\enternote 此处只能进行一次拆分，即\tcode{$a$.$b$.$c$}的当前序列不可能为$a$。\exitnote

\pnum
如果函数调用表达式带有一个闭包块，则这整个块也具有序列作用域，其当前序列确定方法同上。

\enterexample

\begin{codeblock}
let a = [1, 2, 3, 4, 5];
let o = (a: a);

impl int[] : Functor<() -> int[]> {
    func call(&this, index: usize) => 0;
}

impl int[] {
    func v(&this, index: usize) => 1;
}

a[$ - 1] // 当前序列为a
a($ - 1) // 当前序列为a
o.a[$ - 1] // 成员访问，当前序列为o.a
a.v($ - 1) // 方法调用，当前序列为a

\end{codeblock}

\exitexample

\rSec1[name]{名称}
\indextext{名称}

\begin{bnf}{UnqualID}
    Identifier \br
    \terminal{init}
\end{bnf}

\begin{bnf}{FullID}
    UnqualID \br
    UnqualID \terminal{::} FullID \br
    TypeName \terminal{::} FullID
\end{bnf}

\begin{bnf}{EntityID}
    UnqualID \br
    UnqualID \terminal{::} EntityID \br
    TypeName \terminal{::} EntityID
\end{bnf}

\pnum
\term{实体名称}用于要求实体的语法位置（例如类型位置的\tcode{EntityID}、父特征列表），由限定名称构成，最终解析为一个实体。

\pnum
\term{名称}用于引用程序实体。一个\term{未限定名称}可能是一个标识符或关键字\tcode{init}。

\pnum
\term{限定名称}由未限定名称通过\tcode{::}连接而成，用于指定嵌套在其他实体内部的名称。
除最后一个名称之外，其他未限定名称也可以是类型名称。\enterexample 例如\tcode{int::someMethod}。\exitexample

\rSec2[name.lookup]{名称查找}
\indextext{名称查找}

\pnum
\term{名称查找}用于解析一个 \grammarterm{IDExpr} 具体指代的实体。名称的可见范围局域到定义该名称的文件，跨文件引用必须通过导入指令（\ref{import}）显式进行。

\pnum
同一文件内，名称查找从最内层作用域开始向外逐层进行，嵌套作用域中的声明隐藏外层作用域的同名声明。预定义名称（内建类型、核心库的常用类型与函数）通过隐式导入在当前编译单元中直接可用。

\pnum
限定名称\tcode{$A$::$B$}的查找首先解析$A$为实体（类型或模块），然后在$A$的可见范围内查找$B$。$A$可以是模块名称、类型名称或\tcode{root}（当前代码库根目录）、\tcode{this}（当前模块）等上下文关键字。

\pnum
当$A$是类型——包括类型参数、\tcode{self}与\tcode{typeof($e$)}——时，$B$在该类型的成员中查找：具体类型的成员来自其固有实现与特征实现；类型参数的成员来自其约束所绑定的关联类型（\ref{trait}）。查找结果必须唯一：若多个候选满足（例如多个特征各自声明了同名关联类型），则是编译错误，需使用限定形式\tcode{<$A$ as $T$>::$B$}（\ref{type.named}）。

\rSec1[intrinsic]{内建实体}
\indextext{内建实体}

\pnum
\term{内建实体}的实现由编译器提供，而非通过库代码定义。内建实体使用保留标识符 \tcode{__intrinsic} 标记。

\pnum
\tcode{__intrinsic} 只能在 \tcode{core} 库的类型声明中使用，不能在用户代码中出现。类型声明 \tcode{type $T$ = __intrinsic} 表示 $T$ 的类型布局、实例化方式以及相关的运算符实现均由编译器直接提供。语言内建类型（如 \tcode{int}、\tcode{char}）和部分特殊类型均为内建实体。

\pnum
内建类型可以拥有库代码中的附加实现。此时库实现提供该类型的辅助方法和特征，但其基础语义仍然由编译器保证。
